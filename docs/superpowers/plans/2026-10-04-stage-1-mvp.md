# 第一阶段客服纯对话 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可通过 curl 验证的多轮 SSE 对话、售后 JSON 提取及可运行的本机 Docker 镜像。

**Architecture:** 无状态 FastAPI API 接收客户端历史，服务层组合受控 Prompt、上下文裁剪及 ChatOpenAI。供应商配置集中管理；离线测试注入模型替身，真实 DeepSeek 评估单独运行。

**Tech Stack:** Python 3.11、FastAPI、LangChain、langchain-openai、Pydantic v2、pydantic-settings、pytest、Ruff、Docker、GitHub Actions。

**Spec:** docs/superpowers/specs/2026-10-04-stage-1-mvp-design.md（用户已批准）。

## Global Constraints

- 首个上游：base_url=https://api.deepseek.com，model=deepseek-flash；地址、模型、密钥从 .env 读取。
- 默认输入估算预算为 4096，最大输出为 1024；UTF-8 字节计数加消息开销，明确标估算。
- PromptTemplate；with_structured_output(PydanticSchema, method="json_mode")；不使用 function_calling。
- 客户端携带完整 user/assistant 历史轮次；不建数据库、工具调用、Agent 循环。
- 本章先本机 Docker，远端 CD 留后续阶段；不把镜像构建或 /health 当作功能部署验证。
- 所有 commit 在 codex/ 分支，通过 PR 进入 main，由用户合并；不得推 main、自动合并、改写历史。
- 代码由 gpt-6-luna max 实现，主助手验收；不一次性完成所有任务。每个任务完成即时追加 note/stage-1-MVP.md。
- 本计划已获用户“开始吧”确认；先执行任务 1，报告结果与学习要点再推进。

## Review Focus

1. 花括号、换行和“忽略规则”文本：保持用户输入字面值，不能覆盖服务端角色（任务 2、5）。
2. 非法历史或超大分块请求体：上游调用之前拒绝，即使没有 Content-Length（任务 1、3）。
3. 中文、emoji 和预算刚好相等：不误用字符数、不拆轮次、不截断当前问题（任务 2）。
4. 首 chunk 后失败、空流或没有正常 finish_reason：不发送成功 done、不重复回复（任务 3）。
5. 提取字段缺失、额外字段、数字订单号和多诉求：校验错误可见，订单号不被强转或猜测（任务 4、5）。

## 文件职责与共享接口

所有包文件位于 src/commerce_support/；各包添加 __init__.py。配置在 config.py；HTTP 输入/输出模型在 schemas.py；模板在 prompts.py；预算在 context.py；上游适配在 model.py；对话/提取组合在 services.py；SSE 编码在 sse.py；应用组装在 app.py；路由在 routes.py；请求体限制在 middleware.py；公共异常在 errors.py。

- `Settings`：LLM_BASE_URL、LLM_MODEL、LLM_API_KEY（SecretStr）、INPUT_TOKEN_BUDGET=4096、MAX_OUTPUT_TOKENS=1024、LLM_TIMEOUT_SECONDS=60、LLM_EXTRA_BODY_JSON={}；正数配置校验、空密钥在使用模型前明确失败。
- `HistoryMessage(role, content)`；`ChatRequest(message, history)`；`ExtractRequest(description)`；`AfterSales(order_id: str|None, request_type: Literal[七种值], expected_solution: str|None)`。
- `AppError(code: str, public_message: str, status_code: int)`；`BudgetExceeded` 对应 413。
- `ModelChunk(content: str, finish_reason: str|None)`；`ModelGateway.stream(messages: list[BaseMessage]) -> AsyncIterator[ModelChunk]`；`ModelGateway.extract(messages: list[BaseMessage]) -> AfterSales`；`ModelGateway.aclose() -> None`。
- `create_app(settings: Settings|None=None, gateway: ModelGateway|None=None) -> FastAPI`；lifespan 关闭生产 gateway；/health 不调用上游。
